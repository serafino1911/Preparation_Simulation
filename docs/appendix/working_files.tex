\section{Dettaglio Working\_Files}
La cartella include:
\begin{itemize}[leftmargin=1.5em]
  \item template \texttt{*.txt} per generatori input (es. \texttt{terrel\_try.txt}, \texttt{calmet\_try.txt});
  \item script template shell/python in \texttt{Working\_Files/scripts/};
  \item dati di supporto geografico (DEM, landuse) usati dalle finestre dedicate.
\end{itemize}

\section{Flusso dati end-to-end}
\begin{enumerate}[leftmargin=1.8em]
  \item L'utente configura parametri nelle finestre UI.
  \item Ogni finestra salva uno o piu JSON in \texttt{temp\_config/}.
  \item Facoltativamente viene creato uno snapshot in \texttt{saved\_configurations/}.
  \item Operazioni Farm legge \texttt{temp\_config/} e i template in \texttt{Working\_Files/}.
  \item Vengono generati file intermedi in \texttt{Outputs/} e input dedicati in \texttt{*\_INP/}.
  \item Avviene upload/esecuzione remota e successivo download dei risultati.
\end{enumerate}

\section{Note operative}
\begin{itemize}[leftmargin=1.5em]
  \item \texttt{Clear Simulazion} svuota i contenuti temporanei ma mantiene le cartelle.
  \item I database di sorgenti/specie possono essere persistiti in \texttt{saved\_configurations/}.
  \item L'appendice va aggiornata se cambia la struttura directory o il naming dei JSON.
\end{itemize}
